## Lessons this session
- **A lane PR that conflicts with main gets NO pull_request CI.** Only `watch` runs. If `guards` or `pytest-run` never appear on a new head, check mergeability first.
- **CI pins ruff to `>=0.15,<0.16`** (requirements-dev.txt). A lane linting with the box's 0.16.x passes locally and fails CI. Put this in every build brief.
- **Checklist `writeback` and `observation` must be objects.** A string breaks `render_daily_brief.py` and 6 tests.
- **Hold PRs are drafts.** `merge_pull_request` returns 405 until you set `draft=false`. `ready_for_review` does not re-trigger CI, by design.
- **A merge-slot claim file on the branch** plus the `/tmp/.claude-merge-claim-<session>-<pr>` touch satisfies the merge hook.
- **The `accruing` label blocks a pass/fail disposition** unless an `accrual_override_reason` is recorded (`research_disposition.py`). Read that before telling a lane to "accept the label".
