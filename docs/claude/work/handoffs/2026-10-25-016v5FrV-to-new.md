## Lessons this session
- **`branch_slug` strips a leading `claude/`** (`check_pr_landing.py:832`): branch `claude/foo` → `.github/pr-landing/foo.json`. I told lanes the opposite once; the lane read the field and was right.
- **Lane briefs must spell out register schema**: `writeback` exactly `{"roadmap","arch"}`; `observation` `{"what","how_to_check","due_by"}`; new rows need `roadmap` (a **milestone** id from `milestones.yaml`, not a goal like `G3`); hold landings need `hold_reason` from the closed vocabulary + `hold_text` ≥20 chars; a new research script needs a row in `docs/research/RESEARCH-CAPABILITY-INDEX.md`.
- **Manager-scope-guard grades every commit** on a manager branch and forbids writing another branch's merge-slot file; squash your own branch if a bad commit slipped in.
- **Two register PRs editing the same row as a lane PR conflict.** Leave a lane's row to the lane; record dispatch in the lane's own PR or after it merges.
- **Lane reports arrive twice**: lanes create a trigger with `run_once_at` AND `fire_trigger` it, so it fires now and again at the scheduled minute. Delete the trigger after reading (I deleted 3). Fix in the dispatch block / authoring routine prompt: fire immediately, no `run_once_at`.
- **The merge hook keys on `/tmp/.claude-merge-claim-<harness-session-uuid>-<pr>`** (here `779a0173-…`), consumed per merge — re-touch before each retry.
- **Auto-mode classifier can return "no verdict"** transiently for every action; retry once later, do not reword.
