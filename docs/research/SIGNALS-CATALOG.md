> **Relation to the existing register.** The per-input inventory already exists and is CI-guarded: [`docs/reference/signal-catalog.yaml`](../reference/signal-catalog.yaml) (334 inputs: strategy 72 · ml 105 · regime_macro 157; 16 strategy modules; 76 ML models; guard `scripts/ci/check_signal_catalog.py`, row `SIGNAL-CATALOG`), with 20 open research questions in [`signal-catalog-review.md`](../reference/signal-catalog-review.md) — **none of which has become a queue unit** (grep of `research/queue/**` for `signal-catalog-review`, 2026-10-14: 0). It is the **research view the operator asked for on 2026-10-14**: the signals grouped as FAMILIES, each with its definition and code path, producer and store, consumers, **what it should feed** (which model line, which label), and an honest mark of what is **unmeasured** or **unused**. It is the join between M23 meta-labeling and the signal inventory. `signals-catalog.yaml` carries the same facts as data (`feeds:` per family) and points at the per-input ids in the reference register.

**Population of this pass:** `config/strategies.yaml` (55 legs, 8 unit-module families), `config/regime_policy.yaml`, `config/pairs.yaml`, `src/units/strategies/*`, `src/runtime/*` (regime, conviction, telemetry, exits), `src/news/*`, `src/units/strategies/macro_thesis/*`, `ml/datasets/**`, `ml/configs/*.yaml` (73 manifests), `scripts/ml/*`, `scripts/macro/*`, `scripts/research/*`, the committed per-trade ledgers under `comms/strategy_evidence/runs/`. Three read-only code sweeps on 2026-10-14 produced the facts; the lane cross-checked the counts it quotes.

**Vocabulary.** *Producer* = the code that computes the value. *Store* = where a value persists (`—` means computed and dropped). *Consumers* = code that reads the stored value. *Feeds* = the model line or label in `docs/research/programmes/02-AI-TRADER.md` this family should reach. **UNUSED** = stored and read by nothing outside its producer and tests. **UNMEASURED** = computed but never stored or never scored, or a null/stale rate nobody can read. **DEAD DEFAULT** = a column the builder emits as `0.0` when its side-stream is absent, so it exists in the shard without carrying information for that symbol.
